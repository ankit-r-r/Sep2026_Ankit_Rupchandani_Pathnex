## Ansible Task - Install Nginx on Pathnex Server
 
 ---
 - name: Install Nginx on Pathnex Server
   hosts: all
   become: yes
 
 
   task:
     - name: Install Nginx
       yum:
         name: nginx
         state: present

## Kubernetes Task - Create Nginx provider
 
 apiVersion: v1
 kind: pod 
 metadata:
     name: pathnex-pod
 spec:
     containers:
         - name: web
           image: nginx:latest
           ports:
             - containerPort: 80

## Git Integration
## Jenkins Pipeling -- Checkout git
 You will learn how to **checkout a Git Repository** and list files.
 
 
 pipeline{
     agent any
     stages{
         stage('Checkout'){
              steps{
                 git branch: 'main', url: 'https://github.com/Pathnex/sample-java-app.git'
             }
         }
         stage('List Files'){
             steps{
                 sh 'ls -la'
             }
         }
     }
 }
 
 
## GitLab CI - Checkout Git

 stages:
     - checkout
 
 git-checkout:
     stage: checkout
     script:
         - git clone 'https://github.com/Pathnex/sample-java-app.git'
         - cd sample-jave-app
         - ls -la
